# شركة نافذين للمحاماة والاستشارات القانونية | Nafidhayn Law Firm

الموقع الإلكتروني الرسمي، لوحة التحكم الإدارية المركزية (CMS)، ونظام إدارة طلبات الاستشارات والاستفسارات لشركة **نافذين للمحاماة والاستشارات القانونية** (ترخيص رقم 44435 - الرياض، المملكة العربية السعودية).

---

## 🌟 الميزات والمكونات الرئيسية

- **الواجهة العامة الفاخرة (Saudi Legal Elegance):**
  - واجهة معمارية سينمائية تستلهم التراث السعودي والوقار المهني القضائي.
  - دعم كامل للغة العربية (RTL) مع إمكانية التبديل للغة الإنجليزية (LTR).
  - خطوط عربية رصينة: `Amiri` للعناوين الملكية و `IBM Plex Sans Arabic` للنصوص التفاعلية.
  - نموذج حجز استشارات قانونية مبدئية مع التنويه النظامي بعدم تعارض المصالح.
  - نموذج تواصل واستفسارات مباشر مع حماية ضد الرسائل المزعجة (Honeypot).
  - زر عائم للواتساب المباشر مربوط برقم التواصل الرسمي `055 978 7755`.

- **لوحة التحكم المركزية ونظام إدارة المحتوى (`/admin`):**
  - **لوحة المؤشرات العامة:** إحصائيات حية لطلبات الاستشارات والاستفسارات.
  - **إدارة الاستفسارات:** مراجعة الرسائل، تغيير الحالات، وتصدير البيانات إلى Excel (CSV).
  - **إدارة طلبات الاستشارة:** فحص التعارض، المواعيد المبدئية، وإضافة الملاحظات السرية.
  - **محرر المحتوى (CMS):** تعديل نصوص الهيرو والأقسام مع دعم نظام المسودات والنشر المباشر وسجل النسخ السابقة.
  - **الخدمات والأسئلة الشائعة والمقالات:** إدارة وتحديث الخدمات الست المعتمدة ومقالات الأنظمة.
  - **إعدادات الشركة:** تحديث أرقام التواصل والترخيص المهني المعتمد.
  - **نظام الصلاحيات والتدقيق:** حسابات فريق العمل (RBAC) وسجل تدقيق غير قابل للتعديل (Audit Logs).

- **قاعدة البيانات والبنية التحتية:**
  - مربوطة بسحابة **Supabase PostgreSQL**.
  - متوافقة مع النشر السريع على منصة **Vercel**.

## 🚀 التشغيل المحلي (Local Development)

```bash
# تثبيت الحزم البرمجية
npm install

# تشغيل خادم التطوير
npm start
```

- الموقع العام: [http://127.0.0.1:3000](http://127.0.0.1:3000)
- لوحة الإدارة: [http://127.0.0.1:3000/admin](http://127.0.0.1:3000/admin)

## ⚙️ متغيرات البيئة (Environment Variables)

قم بإنشاء ملف `.env` بناءً على `.env.example`:

```env
PORT=3000
NODE_ENV=production

SUPABASE_URL=https://bqgqtirfyquxwfbbtwbi.supabase.co
SUPABASE_ANON_KEY=your_publishable_key
SUPABASE_SERVICE_KEY=your_secret_key
SUPABASE_PROJECT_ID=bqgqtirfyquxwfbbtwbi

ADMIN_JWT_SECRET=your_jwt_secret
```
